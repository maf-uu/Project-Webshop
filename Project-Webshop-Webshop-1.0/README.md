SETUP GUIDE: <br /><br />

Open folder in Visual Studio Code <br />
Open a new terminal <br />
Run "npm install" <br />
Wait for completion <br />
Generate prisma files with "npx prisma generate" <br />
When done, copy over the .env file (this can be acquired by messaging me) <br />
Place .env in root folder <br />
Run nodemon with "npm run dev" (It restarts the server automatically when making changes) <br />
If you wish to view the database contents (data, tables, migrations), message me for link (using Neon) <br />
Open preferred browser, go to url: "localhost:3000/website0.html" <br />
<br />
Enjoy. <br /><br />

ELKEZDÉSI ÚTMUTATÓ <br /><br />

Nyisd meg a mappát Visual Studio Codeban <br />
Nyiss egy új terminált <br />
Futtasd az "npm install" parancsot <br />
Várjad ki a végéig <br />
Generálj prisma fájlokat az "npx prisma generate" paranccsal <br />
Amikor kész, másold át a .env fájlt (megkaphatod he üzensz nekem) <br />
Rakd be a .env fájlt a root mappába <br />

Ha látni szeretnéd az adatbázist (adatok, táblák, migrációk), üzenj a linkért (Neon van felhasználva) <br />
Indítsd el a kívánt webböngészőt, látogass el a "localhost:3000/website0.html" url-re. <br />
