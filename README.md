SETUP GUIDE:

Open folder in Visual Studio Code <br />
Open a new terminal
Run "npm install"
Wait for completion
Generate prisma files with "npx prisma generate"
When done, copy over the .env file (this can be acquired by messaging me)
Place .env in root folder
Run nodemon with "npm run dev" (It restarts the server automatically when making changes)
If you wish to view the database contents (data, tables, migrations), message me for link (using Neon)
Open preferred browser, go to url: "localhost:3000/website0.html"

Enjoy.

ELKEZDÉSI ÚTMUTATÓ

Nyisd meg a mappát Visual Studio Codeban
Nyiss egy új terminált
Futtasd az "npm install" parancsot
Várjad ki a végéig
